Connects to Chapter 19: A photoresist chemically changes solubility where UV exposure reaches it through the mask; positive resist dissolves where exposed, negative resist dissolves where unexposed.

What Each Control Does

Resist type
Positive resist dissolves where exposed; negative resist dissolves where unexposed.
UV dose
Exposure intensity; below a fixed threshold, the resist does not chemically change at all.

Challenge Questions

1. With positive resist and sufficient dose, what remains after development where the mask was open?

Correct. Positive resist becomes soluble where exposed, so it dissolves away during development.

Recall the definition of positive resist given in this chapter.

2. What happens if UV dose is set below the exposure threshold?

Correct. Below the threshold dose, no chemical change occurs in the resist, so no pattern is transferred.

Try setting dose to 0 and observe the Developed row.

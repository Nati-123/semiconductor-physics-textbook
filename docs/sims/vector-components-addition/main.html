Guided Exploration & Challenge Questions

Try This

  • Try this: Set \(|\vec{A}|=5\) and \(\theta_A=0°\), and read off \(A_x\) and \(A_y\) from the numeric panel.
  • Predict: Before setting \(\theta_A=90°\), predict what \(A_x\) and \(A_y\) will become.
  • Observe: Toggle "Show component projections" off and on — what do the dashed lines represent geometrically?
  • Explain: Explain why redrawing \(\vec{B}\) starting from the tip of \(\vec{A}\) (instead of from the origin) still produces the correct resultant \(\vec{R}\).

Connects to Chapter 1: This MicroSim builds the component relationships from the Vectors subsection — \(A_x=|\vec{A}|\cos\theta_A\), \(A_y=|\vec{A}|\sin\theta_A\), and \(|\vec{A}|=\sqrt{A_x^2+A_y^2}\) — the same notation used later for force, field, and the gradient.

What Each Control Does

|A| slider
Sets the magnitude (length) of vector A, shown in blue — magnitude is always zero or positive, since it is a distance.
θA slider
Sets the direction of vector A, measured counterclockwise from the positive x-axis (standard math convention used throughout this course).
|B| and θB sliders
Set the magnitude and direction of vector B, shown in green, independently of A.
Show component projections
Toggles the dashed lines that show \(A_x\) and \(A_y\) as projections onto the axes — turn it off to see just the vectors themselves.

Challenge Questions

1. If \(|\vec{A}|=5\) and \(\theta_A=0°\), what are the components \((A_x, A_y)\)?

At \(\theta=0°\), \(\cos 0°=1\) and \(\sin 0°=0\), so all the magnitude lies along x: \((A_x,A_y)=(5,0)\).

Set the sliders to these exact values in the simulation and read the panel.

2. If \(|\vec{A}|=5\) and \(\theta_A=90°\), what are the components \((A_x, A_y)\)?

At \(\theta=90°\), \(\cos 90°=0\) and \(\sin 90°=1\), so all the magnitude lies along y: \((A_x,A_y)=(0,5)\).

Try it directly: set the sliders and read the component readout.

3. If \(\vec{A}\) has components (3, 4) and \(\vec{B}\) has components (1, 0), what is \(R_x\)?

\(R_x=A_x+B_x=3+1=4\) — components add independently along each axis.

Add only the x-components of A and B together; leave y out of it.

4. When adding vectors "tip-to-tail," where should you draw the start (tail) of vector B?

The tip-to-tail method places B's tail at A's tip; the resultant R then runs from A's tail to B's tip.

Look at the dashed green vector in the diagram above — where does it start?

5. Vector A points due east and vector B points due west with the same magnitude. What is \(|\vec{R}|\)?

Opposite vectors of equal magnitude cancel exactly: their components sum to zero in both x and y.

Try it: set θA=0° and θB=180° with equal magnitudes, and read the resultant.

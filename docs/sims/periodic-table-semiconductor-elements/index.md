<p style="color: #555; line-height: 1.85; font-size: 1.02rem; margin-bottom: 1.2rem;">
This MicroSim presents a focused periodic table covering Groups II through VI across Periods 2–5 — exactly the elements relevant to elemental semiconductors (Si, Ge), III-V and II-VI compound semiconductors (GaAs, InP, CdTe, ZnSe), and common donor/acceptor dopants (P, As, Sb; B, Al, Ga, In).

Guided Exploration & Challenge Questions

Try This

  • Try this: Set \(n=1\) and count the number of nodes in \(\psi_n(x)\) inside the box (there should be none besides the walls).
  • Predict: Before moving the n slider from 2 to 3, predict how many internal nodes \(\psi_3\) will have.
  • Observe: Shrink the box width \(L\) and watch every energy level in the ladder diagram rise — note they do not rise by the same amount.
  • Explain: Explain why \(E_4\) is four times \(E_1\) rather than merely four times as far up the ladder.

Connects to Chapter 2: This MicroSim plots the boxed particle-in-a-box wavefunction \(\psi_n(x) = \sqrt{2/L}\sin(n\pi x/L)\) and energy levels \(E_n = n^2h^2/(8m_eL^2)\) from the chapter, using \(h = 6.626\times10^{-34}\) J·s and \(m_e = 9.109\times10^{-31}\) kg.

What Each Control Does

Box width L slider
Sets the width of the infinite square well, from 0.1 nm to 5 nm — smaller \(L\) pushes all energy levels higher, since \(E_n \propto 1/L^2\).
Quantum number n slider
Selects which stationary state (n = 1 to 6) is plotted — higher n means more nodes and a higher energy.

Challenge Questions

1. How many internal nodes (zero crossings strictly inside the box, not counting the walls) does \(\psi_3(x)\) have?

State n has \(n-1\) internal nodes, so \(\psi_3\) has 2. Set n=3 and count the crossings between the walls to confirm.

Set the n slider to 3 and count the points inside the box (not at the walls) where the curve crosses zero.

2. If \(L\) is cut in half, what happens to \(E_n\) for any fixed n?

\(E_n \propto 1/L^2\), so halving \(L\) quadruples \(E_n\) — try it and watch the ladder diagram shift.

Look at the exponent on \(L\) in the denominator of \(E_n = n^2h^2/(8m_eL^2)\).

3. Why is the energy-level ladder unevenly spaced, with gaps growing wider for higher n?

Since energy scales as \(n^2\), consecutive gaps (\(n^2-(n-1)^2 = 2n-1\)) keep growing — this is exactly what the ladder diagram shows.

Compare the vertical gap between E1-E2 to the gap between E5-E6 in the ladder diagram.

4. What does \(|\psi_n(x)|^2\) represent physically?

The Born interpretation states that \(|\psi(x)|^2\) gives the probability density of finding the particle near x.

Recall the Born rule discussed in the Wavefunction and Probability Density sections of the chapter.

5. Can the particle in the box ever have zero energy?

n = 0 would give \(\psi = 0\) everywhere (no particle at all), which is not a valid state, so the smallest allowed energy is the nonzero \(E_1\) — a direct consequence of confinement, consistent with the uncertainty principle.

Try setting the n slider as low as it goes and read the minimum allowed value.

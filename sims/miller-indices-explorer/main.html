Guided Exploration & Challenge Questions

Try This

  • Try this: Click the (100) preset and rotate the cell — notice the shaded plane is simply the entire face of the cube where \(x=a\).
  • Predict: Before clicking the (111) preset, predict how many corners of the cube the resulting plane will touch.
  • Observe: Click (200) and compare it to (100) — the plane orientation looks identical, but the x-intercept is now half as far out (\(a/2\) instead of \(a\)), because (200) belongs to a more closely spaced family of parallel planes.
  • Explain: Set \(h=0\) and explain, using the readout panel, why the plane never crosses the x-axis no matter how you rotate the view.

Connects to Chapter 3: This MicroSim computes Miller indices the standard way — take a plane's intercepts with the crystal axes in units of the lattice constant \(a\), form the reciprocals of those intercepts, then clear to the smallest integer ratio \((h\,k\,l)\). An index of 0 means the plane is parallel to that axis (intercept at infinity). The shaded plane satisfies \(hX+kY+lZ=1\) in fractional cell coordinates, which is exactly the intercept form of a Miller-indexed plane.

What Each Control Does

h, k, l sliders
Set each Miller index independently from −3 to 3 (integers, 0 allowed). The plane, intercept markers, and readout panel update immediately.
Preset buttons
Jump directly to the common planes (100), (110), (111), and (200) referenced throughout the chapter.
Click-and-drag on the 3D view
Rotates the unit cell so you can view the plane's orientation from any angle (uses p5.js \(\texttt{orbitControl()}\)).
Colored dots on the axes
Mark the x (blue), y (green), and z (orange) intercept points used to derive the current indices.

Challenge Questions

1. What are the (h k l) Miller indices of a plane parallel to the y and z axes, intersecting the x-axis at \(x=a\)?

Intercepts (1, ∞, ∞) give reciprocals (1, 0, 0), so the indices are (100) — try the (100) preset to confirm.

Take the reciprocal of each intercept: 1/1=1 for x, and 1/∞=0 for the axes never crossed.

2. What does an index of 0 mean in Miller notation?

An index of 0 comes from 1/∞ — the plane's intercept with that axis is at infinity, meaning the plane runs parallel to it.

Set one index to 0 with the sliders and read the corresponding intercept line in the readout panel.

3. How do the (100) and (200) planes differ?

(200) is parallel to (100) but its x-intercept is a/2 instead of a — it belongs to a family of planes spaced half as far apart.

Click both presets in turn and compare the plane orientation and the x-intercept value in the readout panel.

4. Which preset produces a triangular plane touching three different cube corners?

(111) has finite intercepts on all three axes at the same distance, producing an equilateral-triangle-shaped plane cutting off one corner of the cube.

Click through each preset and count the sides of the shaded polygon.

5. If you set h = -1, k = 0, l = 0, what happens to the shaded plane in this MicroSim?

The x-intercept works out to -a, which lies outside the [0,a] cell shown, so the readout reports that the plane does not cross this particular unit cell.

Set the h slider to -1 with k and l at 0, and read the warning message in the readout panel.

Guided Exploration & Challenge Questions

Try This

  • Try this: With N=1, rotate the single Simple Cubic unit cell, then move N up to 4 and watch it become a 4×4×4 block built entirely from copies of that same cell.
  • Predict: Before pressing Start at N=3, predict which cell will appear first if cells are revealed in order from the center outward.
  • Observe: Press Start and watch the block grow outward from its center, one cell at a time, until all N³ cells are shown.
  • Compare: Switch structures at the same N and compare how much denser the FCC block looks compared to SC, even though both use the same lattice constant.
  • Explain: Explain why turning off "Show every cell's edges" and looking only at the outer boundary still leaves the atom positions unchanged.

Connects to Chapter 3: This MicroSim makes the lattice/unit-cell relationship from the chapter's introduction concrete: a lattice is the infinite repetition of a single point pattern, and the unit cell (edge length \(a\), the lattice constant) is the smallest repeating block that generates it by simple translation. Here, translating one Simple Cubic, Body-Centered Cubic, or Face-Centered Cubic cell by integer multiples of \(a\) along each axis builds the N×N×N block shown — exactly the construction described before the chapter introduces each structure's specific atom positions.

What Each Control Does

Crystal structure dropdown
Switches the repeating cell between Simple Cubic, Body-Centered Cubic, and Face-Centered Cubic.
Repeat count N slider
Sets how many cells are stacked along each of the three axes, from a single cell (N=1) up to a 4×4×4 block (N=4).
Show every cell's edges checkbox
Toggles between drawing the wireframe outline of every individual unit cell versus only the outer boundary of the whole block.
Atom size slider
Scales every sphere's drawn radius.
Start / Stop (Replay) button
Reveals the block one cell at a time, growing outward from the center, instead of showing it fully built immediately.
Reset Camera button
Returns the view to a default framing sized for the current N.
Click-and-drag / scroll on the 3D view
Rotates and zooms the camera (uses p5.js \(\texttt{orbitControl()}\)).

Challenge Questions

1. What does the N×N×N block in this MicroSim represent?

Every cell in the block uses the exact same atom-position pattern, just translated by whole multiples of the lattice constant a along x, y, and z — this is literally what "a lattice is a repeating unit cell" means.

Set N=1, note the single cell's atom pattern, then increase N and check whether that same pattern repeats.

2. At N=4, how many unit cells make up the block?

N×N×N with N=4 is 4³ = 64 unit cells — read this directly from the readout panel below the canvas.

Set N to 4 and read the "Unit cells shown" line in the readout panel.

3. How wide is the whole N×N×N block, in terms of the lattice constant a?

Each additional cell adds one more lattice constant of length along that axis, so an N-cell-wide block spans N·a in each direction — stated directly in the readout panel.

Read the note in the readout panel below the canvas about how far the block spans.

4. Does turning off "Show every cell's edges" change the atom positions?

The edges checkbox only controls which wireframe lines are drawn (every cell's outline vs. just the outer boundary) — it is a purely visual toggle and never moves an atom.

Toggle the checkbox on and off while watching the atom spheres specifically, not the wireframe lines.

5. When you press Start, in what order are the cells revealed?

Cells are sorted by distance from the block's center and revealed nearest-first, so the block visibly grows outward as more particles appear.

Set N=4, press Start, and watch which cell (relative to the block's middle) appears first.

    Fick's Law and Total Current Density Explorer

    ← Back to Chapter 12: Diffusion and Advanced Transport Phenomena

    Description

    This MicroSim plots an exponentially-decaying hole concentration profile, \(p(x)=P_0e^{-x/L}\), with a movable position marker showing the local tangent line and the resulting diffusion current via Fick's law, \(J_{\text{diff}}=-qD_p(dp/dx)\). Rather than a fixed constant, \(D_p\) is computed live from the Einstein relation using temperature and doping sliders. An electric field slider adds a drift current contribution, combined into a live total current density readout.

    Key Features

    • ● Live tangent line visualizing the local concentration gradient
    • ● Combined drift + diffusion total current readout
    • ● D_p computed live via the Einstein relation, not a fixed constant
    • ● Responsive canvas that resizes with the browser window

    Learning Objectives

    Bloom Level: Apply / Analyze (L3-L4)  |  Bloom Verb: Apply, Combine

    • ✓ Apply Fick's law to compute diffusion current from a concentration gradient
    • ✓ Combine drift and diffusion into a total current density

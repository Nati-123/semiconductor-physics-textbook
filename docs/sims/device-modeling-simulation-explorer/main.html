Challenge Questions

1. Which modeling level does this entire course primarily use?

Correct. Every equation derived across this course — the ideal diode equation, threshold voltage, the Beer-Lambert law, and so on — is an analytic model.

Think about the equations used throughout this course — are they closed-form, or numerically solved on a mesh?

2. Why don't engineers always use full numerical device simulation, if it is the most accurate option?

Correct. Engineers use the simplest model adequate for a given question, reserving expensive numerical simulation for cases that truly need it.

Compare the computational cost bars across all three levels — what trend do you see?

Guided Exploration & Challenge Questions

Try This

  • Try this: Set N_D higher than N_A and confirm the net result is n-type.
  • Predict: Before dragging N_A above N_D, predict what the majority carrier type will become.
  • Observe: Set N_D and N_A to nearly equal values and watch the net doping bar shrink toward zero.

Connects to Chapter 8: A real semiconductor sample can contain both donor and acceptor atoms simultaneously — a compensated semiconductor — whether by deliberate design (counter-doping during fabrication) or unintentional contamination. What matters for carrier type and majority concentration is not either concentration alone but the net doping, \(N_D-N_A\) (n-type if positive) or \(N_A-N_D\) (p-type if positive) — the donors and acceptors partially cancel each other's effect.

What Each Control Does

Donor concentration slider (N_D)
Sets the donor doping concentration.
Acceptor concentration slider (N_A)
Sets the acceptor doping concentration.

Challenge Questions

1. A sample has N_D = 3×10^16 cm^-3 and N_A = 1×10^16 cm^-3. What is the net doping, and what type is the material?

Net doping is N_D − N_A = 3×10^16 − 1×10^16 = 2×10^16 cm^-3. Since this is positive (N_D > N_A), the material is net n-type.

Set the sliders to these approximate values and read the net doping card.

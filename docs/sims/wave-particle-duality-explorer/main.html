Guided Exploration & Challenge Questions

Try This

  • Try this: With two slits open, press Start and watch the first 10-20 particles land — the dots look scattered and random, with no visible pattern yet.
  • Predict: Before letting many more particles accumulate, predict whether the dots will eventually fill in evenly or clump into bands.
  • Observe: Let 100+ particles accumulate with two slits open — distinct bright and dark fringe bands emerge, even though each particle landed individually and unpredictably.
  • Compare: Clear the pattern, switch to "one slit," and build up a new pattern — the fringes disappear, leaving one broad central band. This is the interference term vanishing when there is only one path.
  • Explain: Explain why this experiment shows both particle behavior (individual, localized detections) and wave behavior (a collective interference pattern) at the same time.

Connects to Chapter 2: This MicroSim illustrates wave-particle duality using the same two-path interference logic behind the Davisson-Germer electron-diffraction result described in the text. Each particle is detected as a single, localized dot (particle behavior), yet the accumulated pattern follows the wave-interference intensity \(I(y)\propto\cos^2(\pi d y/\lambda L)\) (wave behavior) — neither description alone explains the full result. Units here are schematic/dimensionless, not literal nanometer-scale distances, since real electron fringe spacing is far too fine to render at canvas scale.

What Each Control Does

Start / Stop button
Starts or pauses firing particles one at a time; each new particle's landing spot is sampled from the interference intensity, then added permanently to the accumulated pattern.
↺ Clear Pattern button
Erases the accumulated dot pattern and resets the particle counter to zero, without changing the slider settings.
Two slits open checkbox
Toggles between one slit and two slits open in the barrier; unchecking it also clears the pattern, since the underlying intensity distribution changes.
Slit separation d slider
Sets the distance between the two slits — larger separation produces more closely spaced fringes.
Wavelength λ slider
Sets the particle's wavelength — longer wavelength produces more widely spaced fringes.

Challenge Questions

1. When two slits are open and many particles have accumulated, what does the resulting pattern show?

The two-slit intensity pattern \(\cos^2(\pi dy/\lambda L)\) has repeating maxima and minima, so particles accumulate into alternating bright fringes (constructive interference) and dark gaps (destructive interference).

Run the simulation with two slits open and let at least 100 particles accumulate before checking the pattern.

2. What happens to the fringe pattern when you switch from two slits to one slit?

With only one slit there is only one path, so there is no second wave to interfere with — the pattern becomes the smooth single-slit diffraction envelope, with no closely spaced fringes.

Clear the pattern, uncheck "Two slits open," and build up a fresh pattern to compare directly against the two-slit case.

3. Each individual particle lands at one specific point on the screen. What does this demonstrate?

A single, sharp landing point per particle is exactly the particle-like half of wave-particle duality — detection is always localized, never spread out like a classical wave.

Watch a single particle travel from source to screen — notice it lands at one sharp point, not a smeared-out region.

4. If you increase the slit separation d, what happens to the fringe spacing?

Fringe spacing is proportional to \(\lambda L/d\), so increasing d in the denominator makes the fringes more closely spaced — read the live "Fringe spacing" readout as you drag the d slider.

Drag the slit separation d slider while watching the predicted intensity curve on the right — count how many peaks fit in the same screen height.

5. Why can't wavelength λ or slit separation d in this MicroSim be read as literal nanometer distances?

The underlying interference math is exactly right, but real de Broglie wavelengths for electrons are sub-nanometer while screens are centimeters to meters away — rendering that ratio on a canvas would make fringes far too fine to see, so the sliders use illustrative schematic units instead.

<h2 style="color: #5A3EED !important; border-bottom: 2px solid #5A3EED; padding-bottom: 0.3rem; font-weight: 700; margin-top: 2rem;">Description</h2>

<p style="color: #555; line-height: 1.85; font-size: 1.02rem; margin-bottom: 1.2rem;">
This MicroSim places a slider-driven dopant concentration marker on the same logarithmic axis as silicon's fixed atomic density (\(5\times10^{22}\ \text{cm}^{-3}\)), across the typical doping range \(10^{13}\)–\(10^{19}\ \text{cm}^{-3}\). A live "1 dopant atom per N silicon atoms" readout converts the huge numeric gap into an intuitive ratio.
</p>

How this map was built: Every arrow in this graph corresponds to a real "builds on" relationship stated in that chapter's own Prerequisites section — nothing here is invented. The five colors group chapters into rough thematic stages: foundational physics and math (Chapters 1-2), crystal structure and band theory (Chapters 3-6), carrier statistics and doping (Chapters 7-10), transport and junctions (Chapters 11-16), and devices and applications (Chapters 17-20).

What Each Control Does

Click a chapter node
Selects it, highlighting its prerequisite arrows (blue, pointing in) and dependent arrows (orange, pointing out) and showing a summary panel in the top-right corner.
Drag a chapter node
Moves that node manually; the force-directed layout keeps adjusting the rest of the graph around it.
Hover over an arrow
Shows a tooltip naming the two chapters that connection joins.
Reset Layout button
Returns every node to a fresh circular starting arrangement.

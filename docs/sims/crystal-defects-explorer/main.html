Connects to Chapter 4: This MicroSim isolates and zooms in on the three point defect types this chapter defines — vacancy, interstitial, and substitutional — matching Worked Examples 7 and 8, which ask students to classify a substitutional phosphorus atom and a vacancy respectively. The chapter singles out the substitutional type as especially important: it is exactly the mechanism Chapter 8 uses deliberately, under the name doping, to engineer a semiconductor's electrical properties.

What Each Control Does

Defect type dropdown
Switches the zoomed-in grid between Vacancy, Interstitial, and Substitutional, updating the diagram and the explanation panel below it.

Challenge Questions

1. A silicon crystal has one lattice site with no atom present, while all neighboring sites are correctly occupied. What type of defect is this?

A missing atom at an otherwise regular site is, by definition, a vacancy — this is exactly Chapter 4's Worked Example 8.

Select "Vacancy" in the dropdown and compare its description to the question.

2. A phosphorus atom sits in a lattice site normally held by a silicon atom. What type of defect is this?

A foreign atom occupying a regular lattice site is a substitutional defect — this is Chapter 4's Worked Example 7, and the same mechanism used deliberately in doping.

Select "Substitutional" in the dropdown and compare its description to the question.

3. Which defect type adds an extra atom that is not part of the regular lattice pattern at all?

An interstitial atom is squeezed into the gap between regular lattice sites — it does not occupy a normal site at all, unlike a substitutional defect.

Select "Interstitial" and look closely at where the orange atom sits relative to the grid lines.

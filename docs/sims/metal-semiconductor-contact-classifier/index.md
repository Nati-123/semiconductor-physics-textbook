<h2 style="color: #5A3EED !important; border-bottom: 2px solid #5A3EED; padding-bottom: 0.3rem; font-weight: 700; margin-top: 2rem;">Description</h2>

<p style="color: #555; line-height: 1.85; font-size: 1.02rem; margin-bottom: 1.2rem;">
This MicroSim classifies a metal-semiconductor contact as <strong>ohmic</strong> or <strong>rectifying</strong> by comparing the metal work function to the semiconductor work function for the chosen doping type. When rectifying, it plots the resulting Schottky diode's thermionic-emission I-V curve on a semi-log chart alongside a fixed p-n diode reference curve, directly visualizing the Schottky diode's much lower forward turn-on voltage.
</p>

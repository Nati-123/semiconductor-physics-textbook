<h2 style="color: #5A3EED !important; border-bottom: 2px solid #5A3EED; padding-bottom: 0.3rem; font-weight: 700; margin-top: 2rem;">Description</h2>

<p style="color: #555; line-height: 1.85; font-size: 1.02rem; margin-bottom: 1.2rem;">
This MicroSim plots the mass action law, \(n_0p_0=n_i^2\), as a straight line on log-log axes (a hyperbola in linear coordinates). An \(n_0\) slider moves a marker along this fixed curve, with \(p_0\) computed automatically so the product always equals \(n_i^2\) for the selected material/temperature preset — directly visualizing how doping trades majority carrier concentration for minority carrier suppression.
</p>

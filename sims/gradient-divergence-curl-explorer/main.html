What Each Control Does

Operator dropdown
Selects which vector-calculus operator is applied: Gradient (turns a scalar field into a vector), Divergence (turns a vector field into a scalar), or Curl (turns a vector field into another vector).
Field dropdown
Selects the preset field the chosen operator acts on — the list of options changes automatically to match the selected operator.

Challenge Questions

1. In Gradient mode with the "Bowl: V = x² + y²" field, which direction do the arrows point at a spot away from the center?

V grows larger farther from the origin in a bowl shape, so the gradient (steepest increase) points outward, away from the center.

Select the Bowl field and look at an arrow near the edge of the grid.

2. In Divergence mode, which field produces a blue background tint (negative divergence)?

The sink field's arrows all point inward, meaning more flow enters than leaves any region — negative divergence, tinted blue.

Switch to each field in Divergence mode and read the numeric ∇·F value at the bottom.

3. In Curl mode, which field produces a nonzero curl (purple tint)?

Only the rotational field's arrows circulate around a point, which is exactly what nonzero curl measures.

Compare the arrow patterns: which one forms circles instead of straight lines?

4. Which operator converts a scalar field (like height or potential) into a vector pointing in the direction of steepest increase?

The gradient is the only one of the three operators whose input is a scalar field and whose output is a vector.

Recall which operator takes \(V(x,y,z)\) as its input in the chapter's definitions.

5. If you placed a tiny paddlewheel at a point in each Curl-mode field, in which field would it spin fastest?

Curl magnitude is proportional to how fast the paddlewheel would spin, and only the rotational field has nonzero curl.

Re-read the paddlewheel analogy in the Curl subsection of the chapter.

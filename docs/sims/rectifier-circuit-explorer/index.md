<h2 style="color: #5A3EED !important; border-bottom: 2px solid #5A3EED; padding-bottom: 0.3rem; font-weight: 700; margin-top: 2rem;">Description</h2>

<p style="color: #555; line-height: 1.85; font-size: 1.02rem; margin-bottom: 1.2rem;">
This MicroSim plots an AC input waveform alongside the resulting <strong>rectifier circuit</strong> output for either half-wave or full-wave bridge rectification, using <strong>power diodes</strong> with a chosen forward voltage drop. The average DC output voltage is computed and marked on the output waveform.
</p>
